# Belajar Web Development 🚀

Repositori ini adalah jurnal dan tempat penyimpanan proyek saya dalam mempelajari Web Development dari nol hingga siap kerja. 

## 🎯 Tujuan
- Menguasai fundamental JavaScript (ES6+).
- Memahami pembuatan REST API menggunakan Node.js & Express.
- Menguasai Database (PostgreSQL) dan Autentikasi (JWT).
- Bisa melakukan Deployment (Render, Railway, Vercel).
- Membangun aplikasi Full-Stack modern dengan React.

## 📂 Struktur Folder
- `/catatan` : Kumpulan catatan materi belajar, tutorial, dan *troubleshooting*.
- `/latihan` : Kode-kode latihan dan proyek kecil (akan datang).
- `/proyek` : Proyek akhir (Capstone) yang siap masuk portofolio (akan datang).

## 🛠️ Tech Stack yang Dipelajari
- **Bahasa**: JavaScript, TypeScript (Dasar)
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL
- **Frontend**: React (akan datang)
- **Tools**: Git, GitHub, VS Code, Postman
